Shroomy is an interactive companion designed to support menstrual health through light, sound, tactile interaction, and data. Supporting bidirectional communication with the app, it enables seamless tracking of cycle phases and well-being patterns. The device uses different-colored lighting to visualize each of the 4 menstrual cycle phases, adapting its intensity to the surrounding environment. 

Personalized reminders for medicine/pill intake can be set up by the user through the mobile app. The reminders are then delivered through sound alerts, which can be stopped using Shroomy’s buttons that automatically sync with the app. Users can quickly log their pain levels by pressing on Shroomy’s head; the longer they press, the more pain.

Components used include:
- Arduino UNO
- NeoPixel 24 LED RGB ring
- Capacitive touch sensor (TTP223)
- 2 Push Buttons
- DFPlayer Mini
- Speaker
- LDR
